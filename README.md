# Alien Terminator

An arcade space shooter made with Python and Pygame. Aliens fall from the top of the screen, you shoot them before they reach you, and the game keeps going until something hits you. The goal is simply to get the highest score you can.

## Gameplay

- Aliens come down in waves of ten. Each one you destroy is worth 10 points.
- Meteorites fall along with them. They can't be destroyed, so you have to dodge them.
- Every 15 aliens you take down charges a special shot with 3 uses. It fires a spread in five directions, and each shot can go through up to four aliens.
- At 100 points the Predator shows up, and it comes back every 200 points after that. It sweeps across the top of the screen firing lasers and takes 5 regular hits to go down. No new alien waves arrive while it's around.
- One touch from an alien, a meteorite, a laser or the Predator ends the game.

## Controls

| Key          | Action                                         |
|--------------|------------------------------------------------|
| ← / →        | Move                                           |
| Space        | Shoot                                          |
| B            | Special shot (when charged)                    |
| ESC          | Back to the menu (quits when in the menu)      |
| ↑ / ↓, Enter | Navigate the menu                              |

## Running the game

You need Python 3.8–3.13 and Git. Pygame doesn't have prebuilt packages for Python 3.14 yet, so stick to 3.13 or earlier.

Clone the repository and create a virtual environment:

```bash
git clone https://github.com/monolith-preacher/alienterminator-project
cd alienterminator-project
python3 -m venv .venv
```

On Windows, use `py -m venv .venv` instead of the last line.

Activate the environment:

| System                 | Command                        |
|------------------------|--------------------------------|
| Linux / macOS          | `source .venv/bin/activate`    |
| Windows (PowerShell)   | `.venv\Scripts\Activate.ps1`   |
| Windows (CMD)          | `.venv\Scripts\activate.bat`   |

Then install the dependencies and start the game:

```bash
pip install -r requirements.txt
python alienterminator.py
```

`python -m alien_terminator` works too. Next time you want to play, just activate the environment and run the game again.

## Running the tests

The game logic is covered by a set of `unittest` tests: movement, shooting, the special shot, the Predator, collisions and scoring, plus checks on the assets and audio loading. They run without opening a window:

```bash
python -m unittest discover -s tests -v
```

## Troubleshooting

- **`externally-managed-environment` when running pip:** the virtual environment isn't active. Activate it and run `pip install` again.
- **PowerShell won't run `Activate.ps1`:** run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` once, or use CMD.
- **No sound:** if no audio device is available, the game still runs, just silently. On WSL, sound goes through the PulseAudio server provided by WSLg; if there's no audio, installing the PulseAudio client library usually fixes it (`sudo apt install libpulse0` on Ubuntu). You can also turn audio off entirely with `SDL_AUDIODRIVER=dummy python alienterminator.py`.

## Project structure

```
alienterminator-project/
├── alienterminator.py     # Entry point
├── alien_terminator/      # Game code
│   ├── app.py             # Main loop, menu and screen flow
│   ├── game.py            # Game rules, collisions and scoring
│   ├── entities.py        # Player, bullets, aliens, meteorites, Predator
│   ├── ui.py              # Menu, HUD and game over screen
│   ├── audio.py           # Sound effects and music
│   ├── assets.py          # Image loading
│   ├── timing.py          # Fixed 60 Hz game update
│   └── config.py          # Game settings
├── tests/                 # Unit tests
├── tools/
│   └── generate_music.py  # Generates the background music
└── assets/                # Sprites, sound effects and music
```
